# Socket 聊天室项目 — 需求规格说明

## 1. 项目概述

基于 **JDK 17** 开发一个 Java 命令行聊天室项目，技术栈涵盖 **Socket 编程、多线程、IO 流** 等核心技术。

## 2. 项目架构

项目采用 **C/S（客户端/服务端）架构**，包含以下两个独立模块：

### 2.1 服务端（Server）

| 模块       | 说明 |
| ---------- | ---- |
| 主线程     | 负责监听并接入客户端连接请求（`ServerSocket.accept()`） |
| 线程池     | 使用线程池技术管理客户端连接，避免为每个连接创建/销毁线程的开销 |
| 子线程     | 每个客户端连接由线程池中的一个线程负责处理 |
| 消息转发   | 子线程接收当前客户端的消息后，将消息**转发给其他所有在线客户端**（群发/广播） |

### 2.2 客户端（Client）

| 模块       | 说明 |
| ---------- | ---- |
| 发送线程   | 独立线程，负责从控制台读取用户输入并发送到服务端 |
| 接收线程   | 独立线程，负责接收服务端转发的消息并打印到控制台 |

## 3. 功能需求

- [ ] 服务端启动后监听指定端口，等待客户端连接
- [ ] 客户端连接成功后可以发送消息到服务端
- [ ] 服务端收到消息后广播给所有在线客户端（除发送者外可选）
- [ ] 客户端断线后服务端自动清理资源
- [ ] 支持多客户端同时在线聊天
- [ ] 客户端显示其他用户发来的消息

## 4. 技术约束

- **JDK 版本**：JDK 17
- **构建工具**：不依赖第三方框架（原生 Java SE）
- **并发模型**：服务端使用 `ExecutorService` 线程池
- **IO 模型**：使用 `java.io` 包中的 BIO（阻塞 IO）流操作

## 5. 运行方式

1. 先启动服务端 `ServerMain`
2. 再启动一个或多个客户端 `ClientMain`
3. 客户端输入消息回车发送，其他客户端实时收到消息
