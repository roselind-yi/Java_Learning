## 1. 数组统计
**需求**：输入5个整数存入数组，计算数组的最大值、最小值和平均值。

**输入示例**：
```
请输入第1个数：10
请输入第2个数：25
请输入第3个数：18
请输入第4个数：32
请输入第5个数：20
```

**输出示例**：
```
最大值：32
最小值：10
平均值：21.0
```

**题解提示**：
- 使用 `Scanner` 循环输入数组元素
- 初始化最大值为数组第一个元素，遍历比较更新
- 初始化最小值为数组第一个元素，遍历比较更新
- 累加所有元素求和，再除以元素个数得到平均值

## 2. 数组反转
**需求**：输入一个数组，将数组元素反转后输出。

**输入示例**：
```
请输入数组长度：5
请输入第1个元素：1
请输入第2个元素：2
请输入第3个元素：3
请输入第4个元素：4
请输入第5个元素：5
```

**输出示例**：
```
原数组：[1, 2, 3, 4, 5]
反转后：[5, 4, 3, 2, 1]
```

**题解提示**：
- 使用双指针法：一个指针从数组开头，一个从末尾
- 交换两个指针指向的元素，然后向中间移动
- 循环条件：头指针 < 尾指针

## 3. 斐波那契数列
**需求**：输入一个整数n，输出斐波那契数列的前n项。（斐波那契数列：1, 1, 2, 3, 5, 8...）

**输入示例**：
```
请输入数列长度：8
```

**输出示例**：
```
斐波那契数列前8项：
1 1 2 3 5 8 13 21
```

**题解提示**：
- 初始化前两个数：a=1, b=1
- 使用循环从第3项开始计算
- 每次计算：c = a + b，然后更新 a=b, b=c
- 注意边界情况：n=1输出[1]，n=2输出[1,1]

## 7. 冒泡排序
**需求**：输入一个整数数组，使用冒泡排序算法对其进行升序排序。

**输入示例**：
```
请输入数组长度：5
请输入第1个元素：3
请输入第2个元素：1
请输入第3个元素：4
请输入第4个元素：2
请输入第5个元素：5
```

**输出示例**：
```
排序前：[3, 1, 4, 2, 5]
排序后：[1, 2, 3, 4, 5]
```

**题解提示**：
- 冒泡排序：重复遍历数组，比较相邻元素
- 如果前一个大于后一个，交换位置
- 外层循环控制排序轮数（n-1轮）
- 内层循环控制每轮比较次数

**输入示例**：
```
请输入数组长度：5
请输入第1个元素：10
请输入第2个元素：20
请输入第3个元素：30
请输入第4个元素：40
请输入第5个元素：50
请输入要查找的目标值：30
```

**输出示例**：
```
目标值30在数组中的索引是：2
```

**题解提示**：
- 使用 `for` 循环遍历数组
- 比较每个元素与目标值
- 找到匹配项返回索引，未找到返回-1

## 10. 生成验证码
**需求**：生成一个6位的随机验证码，包含大小写字母和数字。

**输入**：无

**输出示例**：
```
生成的验证码：A3fG7k
```

**题解提示**：
- 创建包含所有可能字符的字符串：`"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789"`
- 使用 `Random` 类随机生成索引
- 循环6次，每次取一个随机字符拼接成验证码
