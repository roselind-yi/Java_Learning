## 1. 链表实现队列
**需求**：使用链表实现一个队列数据结构，支持入队（enqueue）、出队（dequeue）和查看队首元素（peek）功能。

**输入示例**：
```
请选择操作：1.入队 2.出队 3.查看队首 4.退出
请输入选择：1
请输入入队元素：A
请选择操作：1.入队 2.出队 3.查看队首 4.退出
请输入选择：1
请输入入队元素：B
请选择操作：1.入队 2.出队 3.查看队首 4.退出
请输入选择：3
请选择操作：1.入队 2.出队 3.查看队首 4.退出
请输入选择：2
请选择操作：1.入队 2.出队 3.查看队首 4.退出
请输入选择：4
```

**输出示例**：
```
队首元素：A
出队元素：A
程序退出
```

**题解提示**：
- 创建Node类作为链表节点，包含data和next属性
- 创建Queue类管理队列，维护head和tail指针
- enqueue：在tail后添加新节点，更新tail
- dequeue：移除head节点，更新head，返回数据
- peek：返回head节点的数据但不移除
- 需要处理队列为空的情况

## 2. 学生成绩排序系统
**需求**：创建Student类，输入5个学生的姓名和成绩，按成绩从高到低排序后输出。

**输入示例**：
```
请输入学生数量：3
请输入第1个学生姓名：小明
请输入第1个学生成绩：85
请输入第2个学生姓名：小红
请输入第2个学生成绩：98
请输入第3个学生姓名：小刚
请输入第3个学生成绩：90
```

**输出示例**：
```
按成绩排序后：
1. 小红 - 98分
2. 小刚 - 90分
3. 小明 - 85分
```

**题解提示**：
- 创建Student类，实现Comparable接口
- 重写compareTo()方法，按成绩降序比较
- 使用Arrays.sort()方法对Student数组排序
- 或者手动实现排序算法（如冒泡排序）

## 3. 猜数字游戏升级版
**需求**：
1. 程序随机生成1-100的数字
2. 用户有5次猜测机会
3. 每次猜测后提示剩余次数
4. 游戏结束后显示正确答案和得分（每猜对一次得20分）
5. 支持多轮游戏

**输入示例**：
```
=== 第1轮游戏 ===
猜一个1-100之间的数字：50
太大了！剩余次数：4
猜一个1-100之间的数字：25
太小了！剩余次数：3
猜一个1-100之间的数字：37
恭喜！猜对了！本轮得分：20

是否继续游戏？(y/n)：y

=== 第2轮游戏 ===
猜一个1-100之间的数字：10
太小了！剩余次数：4
猜一个1-100之间的数字：90
太大了！剩余次数：3
猜一个1-100之间的数字：50
太大了！剩余次数：2
猜一个1-100之间的数字：30
太小了！剩余次数：1
猜一个1-100之间的数字：40
太大了！游戏结束！
正确答案是：35

是否继续游戏？(y/n)：n

游戏结束！总得分：20
```

**题解提示**：
- 使用 `Random` 生成目标数字
- 使用外层 `while` 循环控制多轮游戏
- 使用内层 `for` 循环控制5次猜测机会
- 使用计数器记录总得分
- 使用 `Scanner` 接收用户输入判断是否继续

## 4. 图书管理系统（链表增删改查）
**需求**：使用链表实现一个简单的图书管理系统，支持以下功能：
1. 添加图书
2. 删除图书（按书名）
3. 查询图书（按书名）
4. 显示所有图书
5. 退出系统

**输入示例**：
```
请选择操作：1.添加图书 2.删除图书 3.查询图书 4.显示所有 5.退出
请输入选择：1
请输入书名：Java编程思想
请输入作者：Bruce Eckel
图书添加成功！

请选择操作：1.添加图书 2.删除图书 3.查询图书 4.显示所有 5.退出
请输入选择：4
图书列表：
《Java编程思想》 - Bruce Eckel

请选择操作：1.添加图书 2.删除图书 3.查询图书 4.显示所有 5.退出
请输入选择：5
```

**输出示例**：
```
程序退出
```

**题解提示**：
- 创建Book类作为链表节点
- 创建BookList类管理链表
- 实现add()方法在链表尾部添加节点
- 实现delete()方法遍历链表找到匹配节点并删除
- 实现find()方法查找并返回图书信息
- 实现printAll()方法遍历输出所有图书

## 5. 成绩统计分析系统
**需求**：输入多个学生的成绩，进行统计分析：
1. 计算平均分
2. 统计最高分和最低分
3. 统计及格率（60分以上）
4. 统计各分数段人数（0-59, 60-69, 70-79, 80-89, 90-100）

**输入示例**：
```
请输入学生数量：5
请输入第1个学生成绩：85
请输入第2个学生成绩：92
请输入第3个学生成绩：58
请输入第4个学生成绩：76
请输入第5个学生成绩：98
```

**输出示例**：
```
=== 成绩统计分析 ===
平均分：81.8
最高分：98
最低分：58
及格率：80.0%

各分数段人数：
0-59分：1人
60-69分：0人
70-79分：1人
80-89分：1人
90-100分：2人
```

**题解提示**：
- 使用数组存储所有成绩
- 遍历数组计算总分、最高分、最低分
- 统计及格人数计算及格率
- 使用多个计数器统计各分数段人数
- 使用分支结构判断每个成绩所属分数段
