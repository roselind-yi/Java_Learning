## 1. 两个数相加
**需求**：使用Scanner从控制台输入两个整数，计算并输出它们的和。

**输入示例**：
```
请输入第一个数：5
请输入第二个数：3
```

**输出示例**：
```
5 + 3 = 8
```

**题解提示**：
- 使用 `Scanner` 类获取用户输入
- 定义两个变量存储输入值
- 使用 `+` 运算符计算和并输出

## 2. 判断奇偶性
**需求**：输入一个整数，判断它是奇数还是偶数。

**输入示例**：
```
请输入一个整数：7
```

**输出示例**：
```
7 是奇数
```

**题解提示**：
- 使用 `%` 取模运算符
- 判断条件：`num % 2 == 0` 为偶数，否则为奇数

## 3. 判断闰年
**需求**：输入一个年份，判断是否为闰年。闰年规则：能被4整除但不能被100整除，或者能被400整除。

**输入示例**：
```
请输入年份：2024
```

**输出示例**：
```
2024年是闰年
```

**题解提示**：
- 使用逻辑运算符组合条件
- 判断条件：`(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)`

## 5. 计算BMI指数
**需求**：输入身高（米）和体重（公斤），计算BMI指数并输出体型建议。
- BMI < 18.5：偏瘦
- 18.5 <= BMI < 24：正常
- BMI >= 24：偏胖

**输入示例**：
```
请输入身高（米）：1.75
请输入体重（公斤）：65
```

**输出示例**：
```
您的BMI指数是：21.22
体型：正常
```

**题解提示**：
- BMI = 体重 / (身高 × 身高)
- 使用 `if-else if-else` 分支结构判断体型
